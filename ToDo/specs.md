# Plan for a To Do app


Specifications
1. simple to do app. No frills. basic.
2. It should run in a browser
3. Each task has a priority (Low / Medium / High), shown as a colored badge
4. Dark mode toggle, with the choice remembered between visits


Technology
- Plain HTML/CSS/JS, no build tools or frameworks
- Tasks and theme preference persisted in browser localStorage (no backend/server)
